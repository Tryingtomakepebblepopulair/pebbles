# PEBBLES

A block sandbox game for Mac and Windows. Build, dig, explore and survive, alone or together with friends.

## Download

| Computer | File |
|---|---|
| Mac with an Apple chip (M1, M2, M3, M4) | [PEBBLES-Mac.zip](https://github.com/Tryingtomakepebblepopulair/pebbles/releases/latest/download/PEBBLES-Mac.zip) |
| Mac with an Intel chip | [PEBBLES-Mac-Intel.zip](https://github.com/Tryingtomakepebblepopulair/pebbles/releases/latest/download/PEBBLES-Mac-Intel.zip) |
| Windows 10 or 11 (64-bit) | [PEBBLES-Windows.zip](https://github.com/Tryingtomakepebblepopulair/pebbles/releases/latest/download/PEBBLES-Windows.zip) |

**Mac:** open the zip, drag PEBBLES to Applications and open it. If the Mac says it cannot check the app, click Done, then go to System Settings → Privacy & Security and click Open Anyway.

**Windows:** right-click the zip, choose Extract All, and run PEBBLES Setup. If Windows says "Windows protected your PC", click More info, then Run anyway.
